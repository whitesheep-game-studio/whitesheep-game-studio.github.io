# 칸지결 개인정보처리방침 v1.0 변경 기록

2026-11-02. 기존 `/apps/kanjigyeol/privacy/` URL에서 현재 앱 구성을 설명하는 방침 본문을 제공한다. 운영자·연락처, 항목·목적, 기기 저장과 이메일 전송, 90일 이내 문의 삭제, SDK 잠재 처리와 운영 광고 비활성화, 외부 서비스·국외 처리·권리 행사·언어 저장·보호조치·아동·변경 고지를 포함한다.

운영자는 일반 Gmail 사용, 다른 CRM·메일함·외부 업체 자동 전달 없음, AdMob 계정 국가 대한민국을 직접 확인했다. 계정 국가를 이용자 정보의 실제 서버 국가라고 간주하지 않는다. 공개 제공자 문서로 확인할 수 없는 계약 법인·실제 처리국가와 개별 동의의 적법성을 임의 승인하지 않는다. 운영 광고·스토어의 승인 완료를 주장하지 않는다.

한국어 본문의 전체 문단에 일본어·영어 번역을 추가했고 기존 정책 초안에만 존재하던 번역 누락 30개를 baseline에서 제거했다. 새 누락은 추가하지 않았다. 사이트의 기존 65개 한국어 fallback(다른 페이지와 title/meta 등)은 그대로 관리하며 사이트 전체 다국어 완료로 보고하지 않는다.

검증: Python build·내부 링크·해시 무결성 테스트 2개, ESLint·Prettier·html-validate, Vitest 10개, Playwright 데스크톱/모바일 10개와 정책 페이지 axe 심각/중대 오류 없음. 최초 기존 모바일 필터 검사 1개가 선택 메뉴 대기에서 실패했고 소스 변경 없이 단독 재검사 및 전체 재검사에서 통과했다. 이 결과를 버그 수정으로 주장하지 않는다. Lighthouse 기본 두 경로 검사는 통과했으며 경고 기준과 강제 기준을 구분한다.

Node는 저장소 고정 버전 26.13.0을 공식 배포 ZIP과 SHA-256 대조 후 별도 로컬 경로에서 사용했다. 시스템 Node·프로젝트 버전·의존성을 업그레이드하지 않았다. npm ci는 기존 lockfile을 사용했다.

공식 근거와 앱 구성 검증은 앱 저장소의 `docs/privacy/policy_verification_2026-11-02.md`에 기록한다. 이 문서와 브랜치 생성 자체는 공개 배포 완료가 아니다. 공개 반영은 웹사이트 CI 결과와 배포 URL에서 별도로 확인한다.
